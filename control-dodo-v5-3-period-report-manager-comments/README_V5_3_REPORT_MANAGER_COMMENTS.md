# Control Dodo v5.3 — расширенный отчёт + комментарии управляющего

Добавлено:

1. Отчёт контролинга теперь строится за произвольный период:
   - дата начала;
   - дата окончания.

2. В кабинете отображается:
   - сводка по каждой пиццерии;
   - средний балл;
   - количество проверок;
   - активные ошибки;
   - все зафиксированные ошибки;
   - D2;
   - D3;
   - количество удовлетворённых апелляций.

3. Ниже выводится полный реестр ВСЕХ ошибок за выбранный период:
   - дата;
   - пиццерия;
   - проверяющий;
   - зона;
   - время;
   - нарушение;
   - вес;
   - уровень D1/D2/D3;
   - комментарий проверяющего;
   - комментарий управляющего;
   - статус;
   - номер апелляции;
   - комментарий контролинга.

4. Экспорт — Excel (.xls) с двумя листами:
   - «Сводка»
   - «Ошибки»

5. На дашборде управляющий может оставить отдельный комментарий по каждой ошибке.
   Комментарий сохраняется в лист `Ошибки_ID` в колонку:
   `Комментарий управляющего`.

6. Контролинг видит комментарий управляющего:
   - в кабинете;
   - в детальном отчёте;
   - в Excel.

## Установка

1. Заменить Vercel-проект полностью.
2. Заменить Apps Script файлом `APPS_SCRIPT/ControlDodo_FULL.gs`.
3. В Apps Script запустить `installProject` — он добавит новый заголовок
   `Комментарий управляющего` в лист `Ошибки_ID`.
4. Запустить `diagnostic`.
5. Создать новую версию Web App.
6. Проверить, что в Vercel задан APPS_SCRIPT_URL.
7. Сделать Redeploy.
