# Control Dodo v4.7 — статус «Обработана» и блокировка апелляций

Что добавлено:
- После решения апелляции показывается статус:
  - `Обработана · Удовлетворена`
  - `Обработана · Не удовлетворена`
- Обработанная апелляция становится только для чтения.
- Поля статуса, комментария и кнопка сохранения скрываются.
- В кабинете отображается сообщение:
  `Решение уже обработано. Повторное изменение статуса и комментария невозможно.`
- Защита добавлена также на сервере Apps Script: изменить обработанную апелляцию напрямую нельзя.

Что заменить:
1. Vercel-проект — полностью этим архивом.
2. Apps Script — файлом `APPS_SCRIPT/ControlDodo_FULL.gs`.

После замены:
1. Apps Script → сохранить.
2. Запустить `diagnostic`.
3. Развернуть новую версию Web App.
4. Vercel → Redeploy.
