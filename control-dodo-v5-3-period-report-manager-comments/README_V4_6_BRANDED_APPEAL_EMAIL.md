# Control Dodo v4.6 — красивое письмо по апелляции

Добавлено фирменное HTML-письмо в стиле Dodo:

- оранжевая шапка Dodo Control;
- яркий статус:
  - ✅ Апелляция удовлетворена;
  - ❌ Апелляция не удовлетворена;
- блоки:
  - № апелляции;
  - пиццерия;
  - балл;
  - статус;
  - нарушение;
  - комментарий управляющего;
  - комментарий контролинга;
- понятное объяснение:
  - если удовлетворена — баллы возвращаются;
  - если не удовлетворена — балл не меняется.

## Что нужно заменить

Достаточно заменить Apps Script:

`APPS_SCRIPT/ControlDodo_FULL.gs`

Потом:
1. Сохранить.
2. Запустить `diagnostic`.
3. Создать новую версию развертывания Apps Script.

Vercel менять не обязательно, если вы уже используете v4.5.
