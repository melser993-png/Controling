# Control Dodo v4.9 — финальное исправление пересчёта баллов после апелляции

Исправлена причина, из-за которой после удовлетворения апелляции:
- ошибка не удалялась;
- баллы не возвращались;
- SITE_CSV не пересчитывался.

## Причина

В некоторых апелляциях не был записан `ID ошибки`, поэтому Apps Script не мог понять, какую строку в листе `Ошибки_ID` нужно перевести в статус `Удалена по апелляции`.

## Что сделано

Теперь Apps Script ищет связанную ошибку не только по `ID ошибки`, но и по:
- пиццерии;
- дате проверки;
- времени нарушения;
- весу нарушения;
- тексту нарушения;
- комментарию.

Также добавлена функция:

`repairAppealsAndScores`

Она пересчитывает уже обработанные апелляции.

## Как применить

1. Заменить Apps Script файлом:

`APPS_SCRIPT/ControlDodo_FULL.gs`

2. Сохранить.
3. Запустить `diagnostic`.
4. Запустить новую функцию:

`repairAppealsAndScores`

5. После этого проверить:
   - лист `Ошибки_ID`;
   - лист `SITE_CSV`;
   - балл проверки.

6. Затем создать новую версию Web App.
7. Сделать Redeploy в Vercel.

## Логика

Если статус апелляции:

- `Удовлетворена` → ошибка получает статус `Удалена по апелляции`, баллы возвращаются.
- `Не удовлетворена` → ошибка остаётся `Активна`, балл не меняется.
