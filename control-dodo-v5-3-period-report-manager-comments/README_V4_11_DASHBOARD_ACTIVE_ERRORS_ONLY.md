# Control Dodo v4.11 — удаление удовлетворённых ошибок с дашборда

Исправлено:
- после удовлетворения апелляции баллы уже пересчитывались, но ошибка могла оставаться в списке ошибок дашборда;
- теперь дашборд берёт данные напрямую из листа `Ошибки_ID`;
- ошибки со статусом `Удалена по апелляции` не отображаются на дашборде;
- `SITE_CSV` и лист `Проверки` также пересобираются только по активным ошибкам.

## Что заменить

Обязательно заменить Apps Script:

`APPS_SCRIPT/ControlDodo_FULL.gs`

Vercel можно не менять, но лучше заменить весь архив и сделать Redeploy.

## После замены Apps Script

1. Сохранить.
2. Запустить `diagnostic`.
3. Запустить функцию:

`forceRebuildDashboardData`

4. Если есть старые обработанные апелляции, дополнительно запустить:

`repairAppealsAndScores`

5. Создать новую версию Web App.
6. Сделать Redeploy в Vercel.

После этого удовлетворённые ошибки должны исчезнуть из дашборда.
