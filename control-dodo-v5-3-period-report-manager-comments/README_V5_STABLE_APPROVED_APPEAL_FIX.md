## Что исправлено

Если апелляция удовлетворена:

1. Ошибка получает статус `Удалена по апелляции`.
2. Баллы возвращаются.
3. Ошибка исчезает с дашборда.
4. Дашборд строится только по активным ошибкам из `Ошибки_ID`.
5. Добавлена дополнительная защита на стороне сайта: даже если SITE_CSV старый, удовлетворённая ошибка скрывается из дашборда по данным листа `Апелляции`.
