## Как применить

1. Заменить Apps Script файлом:
   `APPS_SCRIPT/ControlDodo_FULL.gs`
2. Сохранить.
3. Запустить `installProject`.
4. Запустить `diagnostic`.
5. Развернуть новую версию Web App.
6. Заменить сайт в Vercel этим архивом.
7. Сделать Redeploy.

## Как сменить пароль

Вариант 1:
- Открыть кабинет → `Пользователи`.
- Нажать `Изменить пароль`.
- Ввести новый пароль.
- Нажать `Сохранить пользователя`.

Вариант 2:
- Открыть лист `Пользователи` в Google Таблице.
- Изменить столбец `Пароль`.
